# Product

## Register

product

## Users

Python developers embed annotation in Dash applications. Their users read source
documents, label exact passages, review existing labels, and export reliable data.
The reference demo is a researcher reviewing a contract at a desk in daylight.

## Product Purpose

Make interactive text annotation a small, installable Dash component. A Python
developer should not need a JavaScript toolchain to use it. Keep document storage,
authentication, and multi-user workflows in the host application.

## Brand Personality

Precise, calm, practical. Prefer familiar controls and clear language.

## Anti-references

Avoid decorative dashboards, promotional statistics, animated introductions,
color-only labels, and hidden destructive gestures.

## Design Principles

- Preserve source text and make annotation changes reversible.
- Make labels and selection state understandable without color.
- Keep the simple embedding API; make advanced controls optional.
- Use maintained browser primitives and annotation libraries.
- Show a complete save and reload workflow in the example.

## Accessibility & Inclusion

Provide keyboard-operable controls, visible focus, labeled inputs, status feedback,
and an alternative to dragging text. Preserve Unicode, whitespace, and text
direction. Respect reduced motion and inherit host-app typography.
